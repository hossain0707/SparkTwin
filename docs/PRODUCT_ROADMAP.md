# Product roadmap

## v0.1.0 — built in source

- Transparent weight/KV/reserve memory estimator and custom device target.
- Scenarios with trade-off variants, local save/load/compare and JSON backup.
- User-observed benchmark import and conservative neighbor calibration.
- Optional read-only SSH Linux memory snapshot with existing OpenSSH aliases.
- Local dashboard, PDF evidence reports, responsive animated brand and architecture documentation.
- Automated tests, unsigned cross-platform CI recipes and detailed workspace handover.

## Next — establish verification, not just features

1. Make GitHub CI matrix and platform preview artifacts pass; no unsigned download claims until verified.
2. E2E desktop/mobile browser tests on normal environments and user feedback on onboarding, accessible keyboard use and chart legends.
3. Real DGX Spark inspection and model-loading/memory acceptance experiments.
4. Model identity (revision/hash), serving backend, quantization packing and GPU allocation metadata in benchmark schema.
5. Calibration validation against held-out data; quantified error bars and stricter provenance checks.
6. Signed Windows/macOS installers, enterprise Linux packaging, SBOM, supply chain review and independent security testing.

## Future commercial differentiation

- Real private infrastructure fleet profiles and signed benchmark evidence bundles.
- Multi-device scheduling/capacity analysis with actual per-device constraints and networking assumptions.
- Enterprise team roles and collaborative on-prem deployments (separate service architecture, auth redesign).
- Validated energy/carbon cost modeling only when real device telemetry supports it.

No paid cloud service or remote telemetry required for the base application.
