How calibration works

Only same-profile, same-precision observations within bounded model-size/context/concurrency distances qualify. Two nearby observations are required. A weighted neighbor estimate and conservative confidence label are shown alongside original sources. There is no extrapolation from NVIDIA's theoretical FP4 performance claim.

What is measured versus modeled?

The optional SSH snapshot reads Linux /proc/meminfo, uname and GPU identity from nvidia-smi -L. It does not collect token throughput, determine true inference allocations, or replace a real benchmark. DGX Spark's memory is unified.

EXPLAINABLE ANALYTICS

Methods & limitations

Understand each assumption before relying on a memory-fit decision.

01 / MEMORY

Model weights

Billions of parameters × bits per weight ÷ 8, multiplied by a configurable packing overhead, converted to GiB.

weights ≈ P × 10⁹ × bits ÷ 8 × overhead
02 / ATTENTION

KV-cache

Two tensors (K and V) × layers × KV heads × head dimension × token count × concurrent sequences × element bytes × utilization.

KV ≈ 2 × L × Hkv × D × T × N × bytes
03 / SYSTEM

Unified memory

DGX Spark's vendor-reported 128 GB is converted to binary GiB. OS, runtime, activation and margin budgets subtract from shared capacity.

headroom = capacity − total estimated use
04 / PERFORMANCE

Measured calibration

Throughput is never manufactured from nominal TFLOPS. Import actual benchmark observations for a cautious interpolation.

Uncalibrated ≠ measured ≠ guaranteed

Implementation boundaries

01 Static, first-order analytical model: no CUDA memory trace, paged KV scheduler, operator-level profiler or simulation of multi-node communication.

02 Performance projections require your benchmark provenance and may not generalize to other kernels, model versions, prompts, thermal conditions or batching policies.

03 The app runs on the operator's computer and makes no cloud calls. SSH inspection uses the system SSH binary with verified known_hosts.

04 Physical DGX Spark and signed cross-platform desktop installers require separate acceptance checks before production use.
